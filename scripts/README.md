# CeloTasks Interaction Scripts

Generates 100+ real onchain interactions on the CeloTasks Mainnet contract.

## Setup
```bash
npm install
```

## Usage
```bash
CREATOR_KEY=0x... WORKER_KEY=0x... node interact.js
```

## Requirements
- Creator wallet: 0.25+ cUSD + 0.1 CELO (gas)
- Worker wallet: 0.05 CELO (gas for submitWork)

## Contract
`0xe289c5F77Bf51BB187C302364b779f4CAF572aEb` on Celo Mainnet
